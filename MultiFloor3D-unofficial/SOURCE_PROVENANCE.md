# Source provenance

This directory is an unmodified, selective extraction of the prototype-fitting
files in `reference_files/multi-floor-3d-code.zip` supplied by the user. The
archive SHA256 is:

```text
3c6fdac970e4b382c190b1e0221b244e97e2ac60ee95856faac17a0c11c939f9
```

Only `fit_prototype.py`, `mesh_fitting_3D/*.py`, the supplied README, and the
supplied install script were extracted. The duplicated, incomplete OneFormer
tree was intentionally not copied. Runtime adaptations belong to the
standalone `houselayout3d` package; these source files remain byte-identical to
their archive entries.
